# 스텔라이브 생방송 알림

Windows용 스텔라이브 방송 알림 프로그램입니다. 멤버별 생방송과 일정을 확인하고 여러 멤버의 치지직 공식 방송을 한 모니터에서 시청할 수 있습니다.

[최신 Windows 실행 파일 다운로드](https://github.com/suei158/stellive-alert-public/releases/latest/download/StelliveAlert.exe)

1. **StelliveAlert.exe**를 원하는 폴더에 저장하고 실행하세요.
2. 설정에서 알림을 받을 멤버와 알림 종류를 선택하세요.
3. **멀티뷰**에서 방송 중인 멤버를 고르고 **같이 보기**를 누르세요. 멤버마다 치지직 공식 방송 창이 열리고, 프로그램 메인 창이 있는 모니터에 자동으로 정렬됩니다. 음량과 화질은 각 방송 창에서 조절합니다.
4. 새 버전이 나오면 실행 중인 프로그램에 알림이 뜹니다. 업데이트를 선택하면 파일을 검증하고 새 버전으로 다시 시작합니다. 취소하면 다음 실행 때 다시 안내합니다.

### X 게시물·스페이스 알림

1. Chrome에서 x.com에 로그인하고 원하는 멤버의 알림을 켜세요. Chrome에서 x.com의 사이트 알림을 허용하고, Windows의 Chrome 알림과 알림 센터 표시도 켜 두세요. 프로그램 팝업과 소리만 원하면 Windows의 Chrome 알림 설정에서 배너와 소리를 끄세요.
2. 프로그램의 **설정 → X 알림 설정**에서 **크롬에서 X 게시물·스페이스 알림 받기**를 켜세요. 같은 화면에서 멤버별로 **새 게시물**과 **스페이스**를 따로 체크한 뒤 설정을 저장하세요. 처음 권한 요청이 뜨면 Windows 알림 접근을 허용하세요.
3. 프로그램이 실행 중일 때 선택한 멤버의 X 푸시 알림이 Chrome에 도착하면 프로그램에도 팝업과 기록이 생깁니다. 스페이스 알림을 클릭하면 전달받은 스페이스 주소를 열고, 전체 주소가 없으면 멤버의 X 프로필을 엽니다. 일정표는 계속 **일정**에서 볼 수 있습니다.

1.0.1로 업데이트하면 이전에 스페이스 일정 알림을 선택했던 멤버가 새 **스페이스** 열로 옮겨집니다. Chrome 연동을 꺼 두었다면 X 알림 설정에서 켜 주세요.

**구형 공개판을 사용 중인 경우** 멀티뷰에서 치지직 공식 방송 창을 여는 공개판 1.0.0은 실행 중 자동 업데이트를 받을 수 있습니다. 이보다 앞서 배포한 구형 공개판은 프로그램을 완전히 종료하고 위 링크에서 받은 EXE로 한 번 교체해 주세요.

변경 사항은 [릴리스 목록](https://github.com/suei158/stellive-alert-public/releases)에서 확인할 수 있습니다.
